Qu'est-ce que le HTML ?

Le HTML (HyperText Markup Language) est le langage qui sert à structurer le contenu d'une page web : les titres, les paragraphes, les images, les liens. C'est le squelette de toute page que vous visitez sur internet.

Pourquoi la sémantique ?

On pourrait tout écrire avec une seule balise passe-partout, et le résultat visuel serait identique à l'écran. Mais une page construite ainsi est illisible pour les technologies qui ne voient pas la page, comme les lecteurs d'écran utilisés par les personnes malvoyantes, ou les robots des moteurs de recherche. La sémantique, c'est choisir une balise qui décrit vraiment le rôle du contenu qu'elle contient.

Les balises sémantiques courantes

L'en-tête de page

Contient le titre du site et les informations d'introduction, généralement en haut de la page. C'est la toute première chose que l'on voit.

La navigation

Regroupe les liens qui permettent de se déplacer dans le site. On y trouve souvent une liste de liens vers les grandes pages ou sections.

Le contenu principal

Il n'y en a qu'un seul par page : c'est le bloc qui contient le cœur du sujet, tout ce qui n'est ni l'en-tête, ni la navigation, ni le pied de page.

Une section et un article

Une section regroupe un ensemble de contenus liés par un même thème. Un article, lui, est un contenu autonome, qui aurait du sens même republié seul ailleurs — comme un billet de blog ou une fiche produit.

Le pied de page

Contient les informations de fin de page : droits d'auteur, contact, liens secondaires. Généralement tout en bas.

Les 3 étapes pour rendre une page plus sémantique

  1. Lire le contenu de chaque bloc et se demander à quoi il sert vraiment
  2. Choisir la balise qui décrit le mieux ce rôle
  3. Vérifier que le rendu visuel n'a pas changé

Le saviez-vous ?

Les lecteurs d'écran permettent aux personnes malvoyantes de naviguer directement d'une balise de navigation à une autre, ou de sauter tout un en-tête pour aller droit au contenu principal. Sans sémantique, cette navigation rapide est impossible.
